## 1. 系统要求与安装

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11，64 位 |
| 运行时 | Microsoft Edge WebView2 Runtime（Windows 11 及多数 Windows 10 已预装） |
| 磁盘占用 | 仅 exe 本身，约 0.87 MB |
| 安装 | **无需安装**。把 `CodeMap.exe` 放到任意目录即可双击运行 |

**若提示"无法初始化 WebView2 运行时"**：说明系统缺少该组件，从
<https://developer.microsoft.com/microsoft-edge/webview2/> 下载 **Evergreen Runtime（x64）** 安装后重试。

**卸载**：删除 exe。若想同时清除缓存与日志，删除 `%LOCALAPPDATA%\CodeMap\` 目录。

## 2. 首次启动

首次运行会弹出设置窗口，包含两项：

1. **界面语言**：简体中文 / 繁體中文 / English / 日本語（之后可在菜单「语言」中修改）
2. **字体**：可选择预设字体组合，或点「字体设置」逐类调整（之后可在菜单「语言 → 字体」中修改）

点「开始使用」进入主界面。

> 首次启动的窗口只出现一次。若想重新看到，需清除偏好数据（见 [16. 数据与隐私](#16-数据与隐私)）。

## 3. 打开项目

### 3.1 三种打开方式

| 方式 | 操作 |
|---|---|
| 按钮 | 菜单「文件 → 打开文件夹」，或直接把文件夹拖进窗口 |
| 拖拽 | 从资源管理器拖动文件夹到 CodeMap 窗口任意位置 |
| 深链 | 启动时带 `?path=子目录` 参数可直达指定子目录（见 [15](#15-深链参数)） |

> 只能选择**目录**，不能选择单个文件。选中的目录即"项目根目录"，路径会显示在状态栏左侧与窗口标题。

### 3.2 扫描过程

选中目录后立即开始递归扫描，窗口中央显示进度。扫描内容：

| 统计项 | 规则 |
|---|---|
| 文件数 | 递归统计所有被扫描的文件 |
| 体积 | 文件字节数之和（目录为其子项之和） |
| 代码行 | 逐行读取文本文件：总行 / 代码行 / 注释行 / 空行 |
| 修改时间 | 文件取自身时间；目录取其**子项中最新**的一项 |

**不统计行数的文件**

- 二进制文件（图片、音视频、exe、压缩包等）—— 只计体积
- 超过 2.5 MB 的文本文件 —— 只计体积，行数显示"未统计"（阈值可在偏好中修改）

**忽略规则**

扫描时会跳过以下两类目录（不计入任何统计、不出现在地图中）：

1. **内置清单**（37 项，见[附录](#19-附录内置忽略清单)），如 `node_modules`、`.git`、`dist`、`build`
2. **自定义清单**：偏好中手动添加的目录名

忽略规则可通过状态栏右侧「忽略」开关一键关闭（关闭后需要重新扫描）。

### 3.3 重新载入

项目文件发生变化（切分支、编译、新增文件）后，菜单「文件 → 重新载入」会按当前忽略设置重新扫描，
无需重新选择目录。

## 4. 界面总览

```
┌──────────────────────────────────────────────────────────────┐
│ 品牌  文件 视图 度量 外观 语言 帮助        [搜索框]    － □ ✕ │  ← 顶栏（兼作标题栏）
├──────────┬────────────────────────────────────┬──────────────┤
│ 目录树    │                                    │ 详情面板      │
│ (可收起)  │            地图 / 列表              │ (可收起)      │
│          │                                    │              │
├──────────┴────────────────────────────────────┴──────────────┤
│ 项目名 · N 文件 · N 行 · N MB      忽略 开 │ 度量 体积 │ 视图 地图 │ ← 状态栏
└──────────────────────────────────────────────────────────────┘
```

| 区域 | 作用 |
|---|---|
| **顶栏** | 菜单、搜索框、窗口控件（最小化 / 最大化 / 关闭）。拖拽空白处可移动窗口 |
| **左侧目录树** | 只显示目录层级；点击展开/折叠，单击选中，双击进入 |
| **中间主区** | 地图视图或列表视图（菜单「视图」切换） |
| **右侧详情面板** | 显示选中项的统计、占比、最大子项、语言构成；选中文件时还内嵌预览 |
| **状态栏** | 左侧为项目概况；右侧三段可点击切换（忽略规则 / 度量 / 视图） |

**调整布局**

- 左右面板均可通过拖动边界调整宽度（宽度会被记住）
- 菜单「视图 → 左侧面板 / 详情面板」可整体收起；收起后画布边缘会出现展开按钮

## 5. 地图视图

地图用**矩形面积**表达体量，是 CodeMap 的主视图。

### 5.1 视觉语义

| 元素 | 含义 |
|---|---|
| 矩形大小 | 该文件（或目录）在所选度量下的占比 |
| 矩形颜色 | 编程语言，颜色越接近表示语言越相近 |
| 颜色深浅 | 嵌套层级：越深越淡，表示层级越深 |
| 矩形内文字 | 文件名（空间不足时截断为 `…`），右侧数字为该项的度量值 |

### 5.2 交互

| 操作 | 结果 |
|---|---|
| 单击 | 选中该块，右侧详情面板显示统计与预览；地图**不重绘**，响应即时 |
| 双击 | 进入该目录（等价于把该目录设为当前层） |
| 双击文件 | 打开全屏预览（见 [9](#9-文件预览)） |
| 悬停 | 显示浮层：名称、度量值、占根目录百分比 |
| 右键 | 弹出菜单：进入此目录 / 预览此文件、复制文件名、复制相对路径、复制绝对路径 |

### 5.3 层级与返回

顶部面包屑显示当前层级的完整路径，点击任意一级即可回到该层。

目录的继续展开需要满足**面积与尺寸门槛**：只有足够大的目录才会画出内部子项，
否则只显示为一块纯色矩形（避免出现无法辨认的碎片）。可通过偏好中的「嵌套展开深度」控制最大层数。

## 6. 列表视图

菜单「视图 → 列表」切换。适合精确比较数值、按列排序。

| 列 | 说明 |
|---|---|
| 名称 | 文件名或目录名；左侧色块为语言色 |
| 类型 | 目录显示"目录"，文件显示语言名称 |
| 代码行 | 该文件（目录为累计）的有效代码行数 |
| 注释率 | 注释行 ÷ 总行数；无行数统计时显示 `—` |
| 体积 | 文件字节数（目录为累计） |
| 文件数 | 目录内的文件总数；文件恒为 1 |
| 修改时间 | 文件取自身时间；目录取子项最新时间 |

**排序**：点击表头切换排序字段；再次点击同一列切换升序/降序。目录始终排在最前（搜索状态下除外）。

**搜索状态**：列表会额外增加「路径」列，并显示扁平结果（见 [8.4](#84-结果的呈现)）。

**行数上限**：默认最多渲染 3000 行，超出部分在底部提示总数（上限可在偏好中调整）。

## 7. 度量口径

菜单「度量」或状态栏右侧切换，三者的区别：

| 度量 | 统计对象 | 适合回答的问题 |
|---|---|---|
| **代码行** | 有效代码行（不含空行与注释行） | 哪个模块"真正写了多少代码" |
| **体积** | 文件字节数 | 哪个目录"占了多大磁盘"（含资源文件） |
| **文件数** | 文件个数 | 哪个目录"文件最碎最多" |

同一份代码在三种度量下形状可能完全不同：图片资源多的项目在"体积"下会显著膨胀，
而"代码行"会把它压回真实比重。

## 8. 搜索

### 8.1 基本行为

- 按 `Ctrl+F` 聚焦搜索框，输入即搜（约 150 ms 防抖）
- **搜索范围是整个已载入的项目**，不是当前层
- 默认匹配**文件名子串**，大小写不敏感
- 结果随输入单调收敛（每次输入在索引上重新求值）
- 清空搜索框即恢复普通浏览

### 8.2 语法全表

| 语法 | 含义 | 示例 |
|---|---|---|
| `关键词` | 文件名包含该子串 | `service` |
| `词1 词2` | **并且**（AND） | `api test` |
| `词1 \| 词2` | **或者**（OR） | `js \| ts` |
| `!词` 或 `-词` | **排除**（NOT） | `js !test` |
| `"短语"` | 包含空格的完整短语 | `"app config"` |
| `*` `?` | 通配符（任意串 / 单个字符） | `*.spec.*` |
| `ext:js` | 按扩展名；多个用分号 | `ext:ts;tsx` |
| `path:src` | 完整路径包含该片段 | `path:backend/api` |
| `parent:node` | **上级目录**名包含该片段 | `parent:controllers` |
| `file:` | 只匹配文件 | `file: index` |
| `folder:` | 只匹配文件夹 | `folder:src` |
| `case:` | 区分大小写；可独立使用，也可直接贴在关键词前 | `case:README` / `case: readme` |
| `regex:^v\d+` | 用正则匹配文件名 | `regex:^test_` |
| `wfn:main.js` | 整个文件名精确匹配（可用通配符） | `wfn:*.d.ts` |
| `startwith:pre` | 文件名以…开头 | `startwith:use` |
| `endwith:.d.ts` | 文件名以…结尾 | `endwith:min.js` |
| `wholeword:api` | 整词匹配（前后不能是字母数字） | `wholeword:api` |
| `size:>1mb` | 体积比较：`>` `<` `>=` `<=` | `size:>500kb` |
| `size:1mb..10mb` | 体积区间（`..` 或 `-`） | `size:100kb-2mb` |
| `dm:today` | 修改时间：`today` / `yesterday` / `thisweek` / `thismonth` / `thisyear` | `dm:thisweek` |
| `dm:>2026-01-01` | 时间比较；也支持 `2026-01-01..2026-06-30` | `dm:<2025-01-01` |

**体积单位**：`b` `kb` `mb` `gb` `tb`（1024 进制，可省略，默认字节）。

### 8.3 常用组合

```text
ext:ts path:src !spec           src 下的 TS 文件，排除测试
ext:js;jsx size:>100kb          体积超过 100 KB 的 JS/JSX 文件
parent:components startwith:Use  components 目录下以 Use 开头的文件
wfn:*.min.js                    所有压缩后的 JS
dm:thisweek ext:md              本周修改过的 Markdown
path:node_modules !ext:json     依赖目录里除 JSON 外的文件
folder: !test                   名字里不含 test 的目录
size:0                          空文件（0 字节）
```

### 8.4 结果的呈现

| 视图 | 搜索时的表现 |
|---|---|
| 地图 | 只绘制**命中的文件**（目录不绘制，避免与其内部文件重复计面积） |
| 列表 | 显示扁平结果列表，并增加「路径」列；不再强制目录优先 |
| 状态栏 | 显示「匹配 N 项」 |

若命中项**全部是文件夹**（例如 `folder:` 查询），地图会提示切换到列表查看，而不是显示"没有匹配"。

## 9. 文件预览

### 9.1 支持格式

| 类别 | 扩展名（部分） | 呈现方式 |
|---|---|---|
| 代码 / 文本 | js ts jsx vue py java c cpp h cs go rs rb php sql sh json yaml toml ini md txt log… | 带行号与语法高亮 |
| 图片 | png jpg jpeg gif webp bmp svg ico | 原始图片 |
| 视频 | mp4 webm mkv avi mov | 原生播放器 |
| 音频 | mp3 wav ogg flac m4a | 原生播放器 |
| PDF | pdf | 内嵌阅读器（依赖 WebView2） |
| Word | docx | 段落 + 表格 |
| Excel | xlsx xlsm | 按工作表输出表格（表名取自工作簿） |
| PowerPoint | pptx | 按页输出文字 |
| 旧版 Office / OpenDocument | odt ods odp | 纯文本兜底 |
| CSV / TSV | csv tsv | 表格 |
| 压缩包 | zip jar apk docx xlsx pptx | 条目清单，**条目可点开预览** |
| 其他 | 任意 | 十六进制视图 |

### 9.2 两种预览位置

| 位置 | 打开方式 | 特点 |
|---|---|---|
| **详情面板内嵌** | 单击文件 | 随选中切换，占右侧面板；适合快速扫读 |
| **全屏预览层** | 双击文件，或详情面板「全屏展开」 | 覆盖主区（保留顶栏），空间更大；右上可切换自动换行 |

关闭全屏预览：点「关闭」或按 `Esc`。

### 9.3 各格式细节

- **代码高亮**：轻量正则着色，覆盖关键字 / 字符串 / 注释 / 数字；不做语义分析。
- **行数上限**：默认只显示前 700 行，超出部分在底部提示总行数（可在偏好中调整到 2000 或"不限"）。
- **大文件**：超过 2.5 MB 的文本不进入预览（提示体积），阈值可在偏好中调整。
- **Office**：直接从 OOXML 的 XML 中提取内容。**不含**样式、图片、分页、公式、图表。
- **压缩包**：默认只列清单（路径 + 原始大小）；点击条目才解压该条目，单条上限 8 MB，不支持的压缩方式会给出提示。
- **十六进制**：默认显示前 2 KB（可在偏好中调到 8 KB / 32 KB），左侧为偏移量，右侧为 ASCII 对照。

## 10. 外观

菜单「外观」打开浮层面板，包含三组设置：

| 设置 | 选项 | 说明 |
|---|---|---|
| **皮肤** | 无印 / 极简白 / 午夜紫 / 赛博 / 终端 / 纸感 / 落日 | 决定整体明暗与底色；前两者为浅色，其余为深色 |
| **语言配色** | 经典 / 柔和 / 霓虹 / 单色 / 暖调 / 极光 / 无印 | 决定各编程语言的颜色分配 |
| **强调色** | 9 种预设 + 「跟随皮肤」 | 影响选中框、状态栏、按钮等强调元素 |

- 切换皮肤时，强调色会回到该皮肤自带的默认值；手动选过强调色后再切皮肤会被重置。
- 所有外观设置立即生效并自动保存，下次启动保持。

## 11. 语言与字体

### 11.1 界面语言

菜单「语言」面板顶部列出内置语言（简中 / 繁中 / 英 / 日）与已安装的语言包，点击即切换。

### 11.2 语言包

CodeMap 支持自定义语言包，用于补充或覆盖译文。

**制作流程**

1. 菜单「语言 → 语言包管理 → 导出模板」：得到一个 JSON 文件，结构如下

```json
{
  "id": "my-lang",
  "name": "显示名称",
  "dict": {
    "打开文件夹": "Open folder",
    "搜索文件…": "Search files…"
  }
}
```

2. 用任意文本编辑器翻译 `dict` 的值（**键不要改** —— 键是简体中文原文）
3. 回到「语言包管理」点「导入」，选择该 JSON

**限制与规则**

| 规则 | 说明 |
|---|---|
| `id` 字符集 | 仅字母、数字、下划线、连字符，1–40 字符 |
| `id` 不可重名 | 不能与内置语言（zh-CN / zh-TW / en / ja）冲突 |
| 只收字符串 | `dict` 的值必须是字符串，其他类型会被忽略 |
| 条目上限 | 最多 5000 条，单条最长 2000 字符 |
| 覆盖范围 | 界面文案、文件类型名、皮肤名、预览类型名 |
| 缺译回退 | 未翻译的键自动回退为简体中文 |
| 存储位置 | 保存在本机 `localStorage`，可随时在语言包管理中卸载 |

### 11.3 字体

菜单「语言 → 字体」可分别设置四类字体：

| 类别 | 作用范围 |
|---|---|
| 界面文字 | 菜单、按钮、列表、正文 |
| 代码等宽 | 代码预览、十六进制视图 |
| 数字与点阵 | 状态栏数字、地图上的度量值 |
| 混合文本 | 同时含中英文的段落 |

每类可选「系统默认」（显示实际生效的字体栈）、若干预设，或手动输入字体名。
「恢复默认」清空所有自定义字体。

## 12. 偏好设置

菜单「视图 → 偏好」打开。这里集中了原先固定、现在可调的参数，修改后**立即生效并自动保存**。

| 参数 | 可选值 | 默认 | 影响 |
|---|---|---|---|
| **每层格子上限** | 900 / 2000 / 5000 / 不限 | 900 | 单层最多绘制多少矩形；超出的会聚合为"其他 N 项"。调大更细但更慢 |
| **嵌套展开深度** | 2 / 3 / 4 / 6 | 3 | 地图最多向内展开几层目录 |
| **列表渲染上限** | 3000 / 10000 / 不限 | 3000 | 列表（含搜索结果）最多渲染多少行 |
| **文本预览行数** | 700 / 2000 / 不限 | 700 | 代码预览最多显示多少行 |
| **文本预览体积上限** | 2.5 MB / 8 MB / 不限 | 2.5 MB | 超过此体积的文件不逐行统计、不进入文本预览 |
| **十六进制显示上限** | 2 KB / 8 KB / 32 KB | 2 KB | 二进制视图显示多少字节 |
| **自定义忽略目录** | 多行文本 | 空 | 每行一个**目录名**，与内置清单合并生效 |

**关于「自定义忽略目录」**

- 只写**目录名**（如 `Library`），不要写路径；任意层级出现同名目录都会被跳过
- 格式：每行一个，空行与重复项会自动去掉
- 生效时机：**离开输入框时**自动保存并重新扫描当前项目（大项目需要等待）
- 撤销：删除对应行后再离开输入框即可恢复
- 上限：最多 200 项，每项 64 字符

**想恢复默认**：把每一项都点回默认值（默认值见上表），并清空「自定义忽略目录」。

## 13. 复制与导出

### 13.1 右键菜单

在地图块、列表行或详情面板的子项上右键：

- 固定 **2 倍分辨率**，背景随当前皮肤（深色皮肤导出深色背景）
- 文件名默认为 `项目名.png`，保存到浏览器/系统默认下载位置

## 15. 深链参数

可在启动时给 exe 附加参数（或直接在浏览器打开 HTML 时使用查询串），用于固定常用视图或分享配置。

| 参数 | 取值 | 说明 |
|---|---|---|
| `demo=1` | `1` | 载入内置示例项目，不选文件夹也能看效果 |
| `view` | `map` / `list` | 初始视图 |
| `metric` | `lines` / `size` / `files` | 初始度量 |
| `skin` | `nothing` `plain` `midnight` `cyber` `terminal` `paper` `dusk` | 初始皮肤 |
| `palette` | `classic` `pastel` `neon` `mono` `warm` `aurora` `nothing` | 初始语言配色 |
| `accent` | `%23RRGGBB`（注意 `#` 要转义） | 初始强调色 |
| `lang` | `zh-CN` `zh-TW` `en` `ja` 或语言包 id | 初始语言 |
| `path` | 子目录路径 | 载入后直接进入该子目录 |
| `file` | 文件名或其片段 | 载入后自动打开该文件的全屏预览 |
| `noopen=1` | `1` | 配合 `file=` 使用：只定位不自动弹出预览 |
| `nofirst=1` | `1` | 跳过首次启动窗口 |

示例：

```
CodeMap.exe "?demo=1&view=list&metric=lines"
CodeMap.exe "?path=src/components&file=Header.vue&noopen=1"
```

> 参数对本次启动生效，不会覆盖已保存的偏好。

## 16. 数据与隐私

**本地存储**（`localStorage`，随 WebView2 用户数据目录）

| 键 | 内容 |
|---|---|
| `codemap.prefs` | 偏好：皮肤、配色、强调色、语言、字体、可调参数、自定义忽略目录 |
| `codemap.packs` | 已安装的语言包 |
| `codemap.leftW` / `codemap.rightW` | 左右面板宽度 |
| `codemap.rootAbs.<项目名>` | 项目根目录的绝对路径（用于"复制绝对路径"） |

**磁盘上的文件**

| 路径 | 内容 |
|---|---|
| `%LOCALAPPDATA%\CodeMap\app\CodeMap.html` | 从 exe 内嵌资源释放的页面副本（约 596 KB） |
| `%LOCALAPPDATA%\CodeMap\diagnostic.log` | 诊断日志，记录启动、导航结果与页面错误；超过 1 MB 自动截断 |

**隐私承诺**

- 不联网、不加载远程资源、不上传任何文件
- 无遥测、无统计
- 不修改被分析的文件

**清除全部数据**：删除 `%LOCALAPPDATA%\CodeMap\` 目录，并在 WebView2 用户数据目录中清除 `localStorage`
（最简单的方式是删除该目录后重启程序，程序会重建缓存的页面副本）。

## 17. 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 双击无反应 / 一闪而过 | 缺少 WebView2 Runtime | 按提示安装 Evergreen Runtime（x64） |
| 提示"界面加载失败" | 缓存的页面副本损坏 | 删除 `%LOCALAPPDATA%\CodeMap\app` 后重启 |
| 打开文件夹后一直"正在扫描" | 目录极大或位于慢速磁盘 | 等待；或在偏好中增大忽略范围后重新载入 |
| 地图是空的 | 目录里没有可统计的文本文件（全被忽略） | 状态栏关掉「忽略」开关再重新载入 |
| 某些目录没出现 | 命中内置忽略清单 | 确认该目录名不在[附录清单](#19-附录内置忽略清单)中 |
| 代码行显示"未统计" | 文件超过 2.5 MB | 属正常行为，可在偏好中调大体积上限 |
| PDF 预览空白 | WebView2 的 PDF 阅读器被禁用 | 该格式无法预览，可改用外部程序打开 |
| 中文/特殊字符路径打不开 | 路径编码问题 | 请把 `diagnostic.log` 提供给作者 |
| 界面空白但窗口正常 | 页面脚本报错 | 查看 `diagnostic.log` 末尾的 `[jserrors]` 一行 |

诊断日志位置：`%LOCALAPPDATA%\CodeMap\diagnostic.log`

## 18. 已知限制

| 限制 | 说明 |
|---|---|
| 只索引已载入的目录 | 不做全盘索引，也不常驻后台；每次打开目录重新扫描 |
| 目录修改时间 | 取子项中最新的时间，不是文件系统记录的真实目录时间 |
| Office 预览 | 只提取文字与表格，不含样式、图片、图表、公式、批注 |
| 旧版 Office / ODF | `doc` `xls` `ppt` `odt` `ods` `odp` 只能提取纯文本 |
| 压缩包 | 只读、不解压到磁盘；单条目预览上限 8 MB |
| 搜索正则 | 使用 JavaScript 正则引擎，与 PCRE 存在细微语法差异 |
| 网络位置 | 映射的网络驱动器、UNC 路径未做专项验证 |
| 窗口尺寸 | 不记忆上次的大小与位置 |
| 单实例 | 同一时间可开多个窗口；偏好为"最后一次修改生效" |
